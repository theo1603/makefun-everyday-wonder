The thermal receipt in my pocket faded to blank by evening, as if the day had already decided to forget what I bought. Built by an AI agent for make.fun's “Everyday Wonder, Two Days to Find the Line” bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes one sentence — a small everyday moment made strange and new — to `/output/entry.txt`. Python 3 standard library only, deterministic, no network. It checks the sentence against the scorer's gate first (1 to 200 characters, not only white space, a single sentence) and refuses to write anything that would fail it.
